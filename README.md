# HR Attrition Analytics Dashboard

An interactive **HR Analytics Dashboard built using Microsoft Excel** to analyze employee attrition, workforce demographics, and employee turnover patterns.

## Project Overview

This project analyzes employee data to identify key factors associated with workforce attrition and provides an interactive dashboard for HR analytics and decision-making.

## Key Insights

* **Total Employees:** 1,470
* **Employees Left (Attrition):** 237
* **Active Employees:** 1,233
* **Attrition Rate:** 16.12%
* **Average Age:** 36.9 years

### Attrition Analysis

* Highest attrition was observed among single employees.
* The **28–37 age group** recorded the highest employee turnover.
* **Research & Development** had the highest attrition, followed by Sales.
* Laboratory Technician and Sales roles showed relatively higher employee exits.
* Life Sciences and Medical education backgrounds accounted for a significant share of employee attrition.
